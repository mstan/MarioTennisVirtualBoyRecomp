# Coverage pass, 2026-10-18

Player version: **0.2.3**. The supported Japan/USA cartridge is the same retail
image (CRC32 `7CE7460D`). No ROM is distributed.

- All seven characters reached actual singles courts and rallies, with zero
  fallback. Corrected doubles routes select all four players and reach courts
  for all seven characters, also with zero fallback. Earlier menu-only doubles
  attempts were excluded.
- Fresh independent Beetle runs cover singles and doubles tournament brackets,
  court entry, rallies, pause and resume: ten checkpoints agree across CPU,
  WRAM, SRAM, VRAM, VIP, devices, both raw eyes and audio; zero fallback.
- The 14-case ROM-free profile is `tests/coverage/suite.json`. It preserves the
  corrected menu choices for repeatable court sampling. It does not establish
  full tournament wins, all tie-break states or complete color artwork coverage.
- Generated functions are split into five translation units. The partition-only
  audit found the original function bodies and dispatch unchanged. Common build
  and debugger fixes live in vbrecomp; recomp-ui uses explicit VB assets.

Reproduce with a development build (native Windows Python 3.11+):

```powershell
.\tools\build.ps1 -Rom 'C:\Games\marios_tennis.vb'
python vbrecomp/tools/run_assisted_suite.py --runtime build/vbrecomp/runtime/MarioTennisVirtualBoyRecomp.exe --rom 'C:\Games\marios_tennis.vb' --suite tests/coverage/suite.json --out validation/courts-new
```

Each output directory must be new. The runner mutes unattended audio output,
keeps emulation active, records execution counters and rejects blank captures
and fallback. Player builds use normal audio. The independent comparison used
a freshly prepared Beetle archive; an existing stale archive is not assumed
compatible with the observation API.

The [original manual](https://www.virtual-boy.com/games/marios-tennis/manuals/956740/)
guided player/mode selection. Color remains optional, version 0.2.2, and unknown
actor poses retain the original ink fallback.
